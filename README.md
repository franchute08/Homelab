# Homelab
Personal homelab built to learn Linux, networking, Docker, cybersecurity and self-hosted services.

## Objectives
-Deploy and maintain self-hosted services
-Improve linux command-line skills
-Learn docker, work with containers and images
-Configure security settings to understand cybersecurity concepts
-Have hands-on projects to better understand about networking concepts

## Server Hardware
| Component | Specification |
|---|---|
| CPU | Intel Celeron J1900 @ 2.00 GHz |
| RAM | 4 GB |
| Storage | 1 TB HDD |
| Operating System | Ubuntu Server 26.04 |
| Architecture | x86_64 |

## Infrastructure
The homelab runs on a dedicated Ubuntu Server machine connected to my local network.
The server has a static IP and uses Docker to run and manage most of its services. Pi-hole is used as the local DNS server.
The homelab is still a work in progress, so the infrastructure and services will evolve over time.

## Services
### Pi-hole
Pi-hole is currently the main service running on the homelab. It acts as the DNS server for my local network and provides network-wide ad and tracker blocking.
### Other Services
Other services will be added to the homelab over time as I continue experimenting with different technologies and use cases.
